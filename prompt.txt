============================================================
1. PRODUCT DEFINITION
============================================================

WinterArc is a DESKTOP-ONLY personal health, fitness, nutrition, recovery,
wellness and analytics application.

It aggregates information from multiple external health/fitness/wellness
applications and presents the result as a beautiful, visual, unified
personal dashboard.

WinterArc is NOT:

- a social fitness application
- a workout-only application
- a calorie tracker only
- a nutrition-only application
- a chatbot
- a raw health-data browser
- a mobile application stretched onto a desktop screen
- a gamified XP/level system
- a spreadsheet disguised as a dashboard

WinterArc SHOULD feel like:

    "A personal health observatory."

The user should open WinterArc and immediately understand:

- How active they have been
- How their recovery is doing
- How they are sleeping
- How their nutrition is doing
- How their body/weight is changing
- How their mental/wellness state is changing
- How these things relate to each other over time

The application should prioritize VISUAL COMMUNICATION over paragraphs of text.

The user should be able to understand most of the dashboard by looking at it,
not reading it.

17. SOURCE PRIORITY / DATA RESOLUTION
============================================================

For example:

    Steps        → preferred source
    Heart rate   → preferred source
    Sleep        → preferred source
    Nutrition    → preferred source
    Workout      → preferred source

If multiple sources provide overlapping information:

1. Use the user's configured priority.
2. Prefer the freshest valid data where appropriate.
3. Avoid duplicate presentation.
4. Handle conflicts deterministically.
5. Preserve source provenance internally.
6. Never silently overwrite data in a destructive way.

The UI should remain clean.

Source management belongs primarily in Settings / Connections.

29. DATA SAFETY
============================================================

Never destroy existing data.

Never silently overwrite user data.

Never perform destructive migrations.
