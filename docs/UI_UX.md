# UI and visualization specification
Desktop-first workstation: silver-white, graphite, charcoal, restrained cool accents, strong typography, minimal decoration. Light/dark themes, CSS tokens, collapsible sidebar, global date range, persistent filters, keyboard access and reduced motion. Avoid generic SaaS cards, excessive glass, gradients and emoji navigation.
Navigation: Overview; Body; Strength; Muscle Recovery; Cardio; Sleep; Nutrition; Mobility; Mood; Habits; Correlation Lab; Gallery; Reports; Sources; Settings. Group related pages.
Charts: time series, rolling averages, stacked bars, scatter, histograms, box plots, calendar heatmaps, correlation matrices, hypnograms, PR timelines and anatomical maps. Reusable metric registry, units, tooltips, zoom, filters, full-screen, PNG/SVG and underlying CSV exports where applicable. Render gaps for missing values. Use licensed anatomical SVG with independently selectable chest, shoulders, arms, back, core, glutes, quads, hamstrings and calves; front/back views, accessible labels and workload legend. Show methodology and confidence on selection.
Gallery: local thumbnails, chronological view, side-by-side and comparison slider. No external photo processing. Animations must not block access. Provide empty, loading, stale and error states. Demo data must be unmistakably separate.
