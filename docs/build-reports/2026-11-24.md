## Launch and reproduction

From `V2/`, create a Python environment, install the runtime dependencies, and start the loopback server:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
PYTHON="$PWD/.venv/bin/python" sh serve.sh
```

Open `http://127.0.0.1:8765/`, or check the API from another terminal with `curl -fsS http://127.0.0.1:8765/api/v1/health`. Set `PORT` before launch to change the port. V2 stores data in `$XDG_DATA_HOME/thewinterarc-v2` when `XDG_DATA_HOME` is absolute, otherwise in `~/.local/share/thewinterarc-v2`; set `WINTERARC_DATA_DIR` to use a separate directory outside Git.
